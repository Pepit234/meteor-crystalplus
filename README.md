# CrystalPlus

Addon para Meteor Client 1.21.11 con módulos avanzados de crystal y mining.

## Módulos
- **AutoCrystalPlus** – Crystal automático inteligente
- **SpeedMinePlus** – Minado rápido por paquetes
- **AutoMinePlus** – Mina el surround del enemigo

## Instalación
1. Descarga el `.jar` de Releases
2. Ponlo en la carpeta `mods` junto con Meteor Client
